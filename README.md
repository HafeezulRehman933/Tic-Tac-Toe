# 🎮 Tic-Tac-Toe Game (C++)

A simple console-based Tic-Tac-Toe game developed using C++.

## 📌 About the Project

This project is a two-mode Tic-Tac-Toe game where players can either play against each other or challenge the computer.

## ✨ Features

- Player vs Player mode
- Player vs Computer mode
- Random computer moves
- Automatic winner detection
- Draw detection
- Play again option
- Interactive console-based board

## 🛠️ Technologies Used

- C++
- Standard C++ Libraries

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in a C++ compiler or IDE.
3. Compile the source code.
4. Run the generated executable file.
